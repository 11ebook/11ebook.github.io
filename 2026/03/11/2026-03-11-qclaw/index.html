1 作为微信通讯器的 QClaw 打开软件后，QClaw 会自动检测你本地有没有装 OpenClaw。 如果有，会提示你关联本地龙虾，这样就不需要迁移配置、skills 这些东西，直接无缝衔接。 现在基本人手一只龙虾，我们先直接选关联。

关联之后，QClaw 会把你和龙虾的对话记录同步到左侧栏。 比如我测试的时候，飞书和 TUI 上跟龙虾的对话流就直接显示了出来。 如果你选择不关联，QClaw 也会帮你一键安装一只新龙虾，零门槛。

重点来了。 登录后，用户可以选择要不要用微信远程操控龙虾。 选择关联微信后，QClaw 会给你一个二维码，微信扫一下就行，非常方便，不用像飞书那样配置 id 和密钥。

但这里要注意，QClaw 在微信里不是以好友的形式出现，而是以客服的形式。 你需要进入客服消息菜单才能找到它，相比飞书、企业微信机器人直接在聊天列表里蹦出来，QClaw 多了一步点击，藏在二级菜单里。 而且客服消息还不能置顶，给人一种，“给你用又不想给你用”的感觉。

基础操作方面，和飞书、钉钉一样，通过微信聊天，可以查看电脑本地文件、修改文件、装了插件还能调用浏览器等。 毕竟 QClaw 本质上还是 OpenClaw。 我尝试了一下最期待的功能，微信和 QClaw 文件互传。

可惜微信并没有进行优化，目前不支持在微信聊天页面直接传。 解决办法是用 imap-smtp-email 技能，简单说就是，走邮箱。 方法和用聚合邮箱软件一样，把授权码告诉 QClaw，它就会操作。

比如我跟 QClaw 说"把桌面的商业文章生成. md 发给我"，它就通过邮件发过来了，我在手机上打开邮箱接收。 反过来也一样，想把手机里的文件发给 QClaw，就给自己邮箱发个附件。

能用，但确实绕了一圈，希望后续能支持微信直传。 又测试了一些其他功能，结果发现在微信上和 QClaw 对话，和飞书、钉钉端的体验基本一致。 换句话说，QClaw 与微信连接，也仅仅是连接，微信并没有进行深度适配，那些期待 QClaw 作为机器人帮你管理好友，在微信群里帮你总结消息的功能，还没有。

当然能让龙虾连接到中国最大的社交工具，本身就是腾讯此阶段必须要用某种方式展示的优势。 1 QClaw 就是小白友好的OpenClaw 那抛开微信，QClaw 还有什么不同？ 我把原版 OpenClaw 删了，装了个纯净的 QClaw，发现还真不一样。

用 QClaw 新装龙虾的话，首页就让你选模型。 默认会从 Kimi K2.5、Minimax M2.5、DeepSeek V3.2 里随机分一个给你，当然也可以用 API 接自己的。 不用纠结选哪个，打开就能用，对小白来说省心不少。

另外QClaw 的内置技能也有亮点，这些东西原版 OpenClaw 完全没有。 第一个，qclaw-rules，作用很简单：强制中文回复。 系统提示词里写死了，所有对话、报错都必须用中文，代码和技术名词除外。

再也不用反复跟龙虾说"请用中文回复我"了。 第二个，qclaw-env，主要是解决网络问题。 我们经常看到 AI 教程说"一句命令就能装好"，结果你一上手，超时，失败，这也是为什么安装龙虾价值 500元的主要原因。

qclaw-env 会先检测你能不能连上 GitHub、npm、PyPI，连不上就自动切其他镜像。 响应超过 2 秒直接建议你配镜像。 就这一个功能，能帮小白省掉无数次"为什么又装失败了"的崩溃。

第三个，qclaw-openclaw，管龙虾配置的。 原版 OpenClaw 假设你熟悉命令行，先 npm install -g openclaw 全局安装，再手动 openclaw gateway start 启动服务。 终端一关，服务就断。

光是终端黑不溜秋的页面，就能劝退不少人。 QClaw 直接把这些砍了。 不用全局安装任何东西，服务由应用本身托管，双击打开就在跑，崩了自动重启。

可以避免小白用户把龙虾搞崩溃。 第四个是做安全审查的 skill-vetter。 小白从网上找到一个 skill 想装，根本不知道代码里写了什么。

原版 OpenClaw，直接装，用户完全裸奔，最近也爆料出不少 OpenClaw 的安全问题。 QClaw 在装 skill 之前先扫一遍脚本，有没有 rm -rf /、curl | bash 这种危险操作，权限申请合不合理，一个查天气的 skill 要管理员权限？ 明显有问题。

审核后会告诉用户这些代码有什么问题。 最后一个技能 find-skills，解决"找 skill"的问题。 原版的技能生态基本是英文的，国内用户搜都不知道搜什么。

find-skills 可以直接用中文搜，比如"小红书工具""微信机器人"，自动匹配，优先推荐适配国内平台的，安装走 Gitee 镜像加速。 1 连微信不是重点，不掉队才是 QClaw 的最大的亮点，不是连微信而是小白友好。 微信那头的体验说实话还挺粗糙的，客服入口藏在二级菜单，文件互传还得绕邮箱，想让龙虾帮你管群消息、加好友？

没有。 目前的微信连接，更像是"能用"，而不是"好用"。 真正让我觉得不一样的，是那五个内置技能。

强制中文、自动配镜像、双击就跑的服务托管、安装前的安全扫描、中文搜 skill，这些东西单个拿出来都不算大功能，但加在一起，是第一次有人认真替国内小白用户想了一遍体验。 原版 OpenClaw 是极客做出来给极客用的，QClaw 想让不会折腾的人也能用上龙虾。 方向是对的，虽然每个功能都还有打磨空间。

那问题来了：微信连接既然体验这么初级，腾讯为什么还要急着推？ 因为龙虾能连飞书、能连钉钉、能连企业微信，唯独连不上个人微信。 飞书和钉钉本质是工作软件，用户量和使用时长没法跟微信比，但偏偏是它们先让用户随时随地在聊天里调用 AI。

如果"和 AI 对话"这个场景被别人吃掉，哪怕只吃掉一部分，对腾讯来说都是个危险信号。 14 亿月活的入口，不能在 AI Agent 时代缺席。 QClaw 是腾讯补这个缺口的第一步。

用客服形式接入，不侵入好友列表，克制但也受限。 而就在QClaw开始发放测试资格的同时，已经有消息传出，微信也在秘密开发一款Agent，计划通过对话框直接嵌入这款国民应用中。 腾讯吃虾是停不下来了。
